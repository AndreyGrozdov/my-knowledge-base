## 1. Создать очередь
```curl -u admin:(pass) -X PUT http://localhost:15672/api/queues/%2F/test_queue -H "Content-Type: application/json" -d '{"durable":true}'
```

## 2. Отправить сообщение
```curl -u admin:(pass) -X POST http://localhost:15672/api/exchanges/%2F/amq.default/publish -H "Content-Type: application/json" -d '{"properties":{},"routing_key":"test_queue","payload":"Hello from curl","payload_encoding":"string"}'
```

## 3. Забрать сообщение
```curl -u admin:(pass) -X POST http://localhost:15672/api/queues/%2F/test_queue/get -H "Content-Type: application/json" -d '{"count":1,"requeue":false,"ackmode":"ack_requeue_false","encoding":"auto"}'
```

## 4. Удалить очередь
```curl -u admin:(pass) -X DELETE http://localhost:15672/api/queues/%2F/test_queue
```
